# Button

Bouton d'action standard, en capitales, avec 4 variantes : primary (ambre), secondary (contour), accent (orange) et ghost.

- Un seul `primary` par écran : c'est l'action que la salle éclaire. Au survol, il prend la lueur `glow`.
- `accent` sert aux actions média (bande-annonce, lecture).
- Le libellé est un verbe : *Noter*, *Écrire une critique*.
- Tailles `sm` 32px, `md` 44px, `lg` 52px. Icône optionnelle (`icon`).

À fournir : `children` (libellé), `onClick`.

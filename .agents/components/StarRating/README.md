# StarRating

Notation sur 5 étoiles au demi-point près, en lecture ou en interactif.

- Étoile pleine `amber`, demi-étoile `amber-soft`, étoile vide en contour `line`.
- En interactif (`interactive`), chaque étoile a deux zones de clic : la moitié gauche pour le demi-point, la droite pour le point entier.
- `showValue` affiche la note en Bebas Neue. Une note ≤ 2 passe en `ink-muted` (on éteint la lumière, on ne met pas de rouge).
